## Mining Quiz: Question #1

**Which of the following statements about mining are correct?**

### Answer Choices

**1.** When a cryptocurrency has been mined, the supply of that cryptocurrency increases.

**2.** All cryptocurrencies have an unlimited supply of cryptocurrencies that can be mined.

**3.** Mining is only possible if you mine as part of a pool of other miners.

**4.** The maximum number of Bitcoins in the long run is 100,000,000 Bitcoins.

## အဖြေ

**Correct Answer: 1.**

> **When a cryptocurrency has been mined, the supply of that cryptocurrency increases.**

### ဘာကြောင့် No.1 မှန်တာလဲ?

Bitcoin Mining ကို ဥပမာယူကြည့်ရအောင်။

Miner တစ်ယောက်က **Proof of Work (PoW)** ကို ဖြေရှင်းပြီး Block တစ်ခုကို successfully mine လုပ်တဲ့အခါ... protocol သတ်မှတ်ထားတဲ့ **Block Reward** အနေနဲ့ Bitcoin အသစ်တွေ ထုတ်ပေးနိုင်ပါတယ်။

ဒါကြောင့်...

**Mining → New Bitcoin issuance → Circulating supply တိုးလာနိုင်ခြင်း**

ဆိုတဲ့ ဆက်စပ်မှုရှိပါတယ်။

ဥပမာ...

```text
Miner
   ↓
Proof of Work
   ↓
Valid Block
   ↓
Block Reward
   ↓
New BTC issued
   ↓
Bitcoin supply increases
```

---

### No.2 ဘာကြောင့်မှားလဲ?

> **All cryptocurrencies have an unlimited supply...**

Cryptocurrency အားလုံးမှာ supply unlimited မဟုတ်ပါဘူး။

Bitcoin မှာတော့ protocol အရ **maximum supply = 21 million BTC** ဖြစ်ပါတယ်။

ဒါကြောင့် "All cryptocurrencies" လို့ အားလုံးကိုခြုံပြောထားတဲ့ statement ဖြစ်လို့ **မမှန်ပါဘူး**။

---

### No.3 ဘာကြောင့်မှားလဲ?

> **Mining is only possible if you mine as part of a pool...**

Mining Pool ထဲဝင်ပြီး mining လုပ်နိုင်တာမှန်ပါတယ်။

ဒါပေမယ့် **Mining Pool မဝင်ဘဲ Solo Mining** လုပ်နိုင်ပါတယ်။

```text
Mining
 ├── Solo Mining
 └── Mining Pool
```

Mining Pool က miners တွေရဲ့ **Hash Power** ကို စုပေါင်းပြီး block reward ရရှိတဲ့အခါ contribution အလိုက် ခွဲဝေပေးတဲ့ပုံစံပါ။

ဒါကြောင့် "only possible" ဆိုတာကြောင့် No.3 မှားပါတယ်။

---

### No.4 ဘာကြောင့်မှားလဲ?

> **The maximum number of Bitcoins ... is 100,000,000 Bitcoins.**

ဒီမှာ **100,000,000** ဆိုတာ Bitcoin ရဲ့ maximum supply မဟုတ်ပါဘူး။

Bitcoin ရဲ့ maximum supply က...

**21,000,000 BTC**

ဖြစ်ပါတယ်။

**100,000,000** ဆိုတာကတော့ **1 BTC = 100,000,000 Satoshis** ဆိုတဲ့အချက်နဲ့ ဆက်စပ်ပါတယ်။

```text
1 BTC
  ↓
100,000,000 Satoshis
```

ဒါကြောင့် **100 million** ကို Bitcoin အရေအတွက်နဲ့ မရောသင့်ပါဘူး။

---

## မှတ်ထားရမယ့်အချက်

ဒီ Question မှာ အဓိကမှတ်ရမှာ ၄ ခုပါ...

| Concept                | မှတ်ရန်                                    |
| ---------------------- | ------------------------------------------ |
| Mining                 | New coins issuance နဲ့ ဆက်စပ်နိုင်တယ်      |
| Bitcoin Maximum Supply | **21 million BTC**                         |
| Mining Pool            | မဖြစ်မနေမဟုတ်ဘူး... Solo Mining လည်းရှိတယ် |
| 100 million            | **1 BTC = 100 million Satoshis**           |

### Quiz Answer

**Question #1 → Answer: 1**

> **When a cryptocurrency has been mined, the supply of that cryptocurrency increases.**
