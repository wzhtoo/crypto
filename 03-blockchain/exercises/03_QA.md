# Blockchain Quiz

## Question #3

### မေးခွန်း

**All blocks contain a link to the previous block, except:**

1. The first block.
2. Block number 24601.
3. The second block.
4. The third block.

### အဖြေ

**အဖြေမှန် - 1. The first block.**

---

## ရှင်းလင်းချက်

Blockchain ရဲ့ အရေးကြီးတဲ့ အချက်တစ်ခုက **Block တစ်ခုဟာ သူ့အရင် Block ကို Link ချိတ်ထားတာ** ဖြစ်ပါတယ်။

ဥပမာ...

**Block 1 → Block 2 → Block 3 → Block 4**

ဒီလို Block တွေဟာ အစဉ်လိုက် ချိတ်ဆက်ထားပါတယ်။

### Block 2

Block 2 ထဲမှာ **Block 1 ရဲ့ Hash** ကို သိမ်းထားပါတယ်။

```text
Block 1
   ↓
Hash
   ↓
Block 2
```

ဒါကြောင့် Block 2 က သူ့အရင် Block ဖြစ်တဲ့ Block 1 ကို ပြန်ညွှန်းနိုင်ပါတယ်။

### Block 3

အလားတူ Block 3 ထဲမှာ **Block 2 ရဲ့ Hash** ပါဝင်ပါတယ်။

```text
Block 1 → Block 2 → Block 3
             ↑
        Previous Hash
```

### First Block / Genesis Block

ဒါပေမယ့် **First Block** ကိုတော့ **Genesis Block** လို့ ခေါ်ပါတယ်။

Genesis Block ဟာ Blockchain ရဲ့ **ပထမဆုံး Block** ဖြစ်တဲ့အတွက် သူ့အရင်မှာ Block မရှိပါဘူး။

ဒါကြောင့် သူ့အရင် Block ကို Link ချိတ်စရာ မရှိပါဘူး။

---

### အကျဉ်းချုပ်

**Block တစ်ခုရဲ့ Previous Block Link**

```text
Genesis Block → Block 2 → Block 3 → Block 4
      ❌             ↑          ↑
  Previous       Previous    Previous
   Block မရှိ      Block 2     Block 3
```

ဒါကြောင့် **“All blocks contain a link to the previous block, except...”** ဆိုတဲ့ မေးခွန်းရဲ့ အဖြေက...

**1. The first block.** ဖြစ်ပါတယ်။

> **မှတ်ရန်:** First Block = **Genesis Block** = Blockchain ရဲ့ အစပြု Block.
