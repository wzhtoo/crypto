# Blockchain Quiz

## Question #1

### မေးခွန်း

**Traditional (non-digitized) ledgers တွေရဲ့ ပြဿနာက ဘာတွေလဲ။**

1. Transaction တစ်ခုမှာ ပါဝင်သူအများစုက Ledger ကို ဝင်ရောက်ကြည့်ရှုနိုင်ခြင်းမရှိတာကြောင့် **Transparency** နည်းပါးတယ်။
2. အများအားဖြင့် Ledger ရဲ့ **Backup** မရှိတာ၊ ဒါမှမဟုတ် Backup မလုံလောက်တာ ဖြစ်တတ်တယ်။
3. **Old-school / non-digitized ledgers** ကို အသုံးပြုတဲ့အခါ Bank တွေက Fee အတော်များများ ကောက်ခံနိုင်တာကြောင့် ကုန်ကျစရိတ် ပိုမြင့်နိုင်တယ်။
4. **အထက်ပါအချက်အားလုံး မှန်ကန်သည်။**

## ရှင်းလင်းချက်

ဒီမေးခွန်းမှာ **Traditional (non-digitized) Ledger** ဆိုတာကို အရင်နားလည်ဖို့လိုပါတယ်။

**Ledger** ဆိုတာက Transaction တွေ၊ ငွေဝင်ငွေထွက်တွေ၊ ပိုင်ဆိုင်မှုဆိုင်ရာ အချက်အလက်တွေကို မှတ်တမ်းတင်ထားတဲ့ စာရင်းစာအုပ် သို့မဟုတ် Record တစ်ခု ဖြစ်ပါတယ်။

Traditional Ledger တွေမှာ အဓိကပြဿနာ ၃ ခု ရှိပါတယ်။

### 1. Transparency နည်းပါးခြင်း

Traditional Ledger ကို Transaction မှာ ပါဝင်သူတိုင်းက ကိုယ်တိုင် ဝင်ရောက်ကြည့်ရှုနိုင်တာ မဟုတ်ပါဘူး။

ဥပမာ...

Bank တစ်ခုမှာ ငွေလွှဲတဲ့အခါ Transaction Record ကို Bank ရဲ့ System ထဲမှာ သိမ်းထားပါတယ်။ Customer က Ledger တစ်ခုလုံးကို ကိုယ်တိုင် ဝင်ကြည့်ပြီး စစ်ဆေးနိုင်တာမျိုး မဟုတ်ပါဘူး။

ဒါကြောင့် **Transparency** ပိုင်းမှာ ကန့်သတ်ချက်ရှိပါတယ်။

### 2. Backup မလုံလောက်ခြင်း

Traditional Ledger တွေဟာ Paper Record ဒါမှမဟုတ် Local Record အဖြစ် ရှိနေနိုင်တာကြောင့် Backup မရှိတာ၊ Backup မလုံလောက်တာမျိုး ဖြစ်နိုင်ပါတယ်။

ဥပမာ...

စာရင်းစာအုပ်တစ်အုပ်တည်းမှာပဲ Record တွေ သိမ်းထားပြီး အဲဒီစာအုပ် ပျောက်သွားတာ၊ ပျက်စီးသွားတာဆိုရင် Record တွေ ဆုံးရှုံးနိုင်ပါတယ်။

### 3. Fee မြင့်မားနိုင်ခြင်း

Traditional Financial System တွေမှာ Transaction တစ်ခုလုပ်တဲ့အခါ **Bank** လို Intermediary တွေ ပါဝင်နိုင်ပါတယ်။

အဲဒီ Intermediary တွေက Service Fee, Transaction Fee စတာတွေ ကောက်ခံနိုင်တာကြောင့် Transaction Cost ပိုများနိုင်ပါတယ်။

### အကျဉ်းချုပ်

ဒါကြောင့် မေးခွန်းမှာ ဖော်ပြထားတဲ့...

**Transparency နည်းပါးခြင်း + Backup မလုံလောက်ခြင်း + Fee မြင့်မားနိုင်ခြင်း**

ဆိုတဲ့ အချက် ၃ ခုလုံးကို ပြဿနာတွေအဖြစ် ဖော်ပြထားတာကြောင့်...

**အဖြေမှန်က 4. All of the above are correct.** ဖြစ်ပါတယ်။
