# Blockchain ဆိုတာ Digital Ledger System တစ်ခုပါ

Crypto နဲ့ Blockchain အကြောင်း လေ့လာလာရင်း ကျွန်တော် စိတ်ဝင်စားလာတာက Blockchain ရဲ့ နောက်ကွယ်မှာရှိတဲ့ အခြေခံအယူအဆဖြစ်တဲ့ Ledger System ပါ။ အရင်ခေတ်က လူတွေက ငွေဝင်ငွေထွက်တွေကို စာအုပ်ထဲမှာ မှတ်တမ်းတင်ကြပါတယ်။ ဘယ်သူ့ဆီက ငွေရသလဲ၊ ဘာအတွက်သုံးသလဲ၊ ဘယ်လောက်ကျန်သေးသလဲဆိုတာကို Ledger Book ထဲမှာ ရေးမှတ်ထားကြတာပါ။

ဒီနေရာမှာ စိတ်ဝင်စားစရာက...

နှစ်ပေါင်းများစွာကြာသွားပေမယ့် ငွေကြေးမှတ်တမ်းတင်တဲ့ စနစ်နဲ့ ငွေလွှဲတဲ့အခါ ပေးရတဲ့ Bank Fees၊ Accounting Fees၊ Legal Fees နဲ့ International Transfer Fees တွေဟာ ယနေ့ခေတ်အထိ လုံးဝမပြောင်းလဲသေးဘူးဆိုတဲ့ အယူအဆပါ။ အဲဒီလိုနဲ့ Blockchain ရဲ့ အခြေခံအကြောင်းအရာကို စတင်နားလည်နိုင်ပါတယ်။ Blockchain ဆိုတာ Digital Ledger System တစ်ခုပါ။

ရိုးရိုး Ledger Book နဲ့ မတူတာက Transaction Data တွေကို Digital Format နဲ့ သိမ်းဆည်းပြီး Block တွေအဖြစ် စုစည်းထားပါတယ်။ အဲဒီ Block တွေကို အစီအစဉ်တကျ ချိတ်ဆက်ထားတာကြောင့် Blockchain လို့ခေါ်တာပါ။

Blockchain မှာ...

- Block ဆိုတာ Transaction Data တွေ စုစည်းထားတဲ့ အစုအဝေးတစ်ခုပါ။
- Chain ဆိုတာ Block တစ်ခုနဲ့တစ်ခု ချိတ်ဆက်ထားတဲ့ စနစ်ပါ။
- Hash ဆိုတာ Data တွေရဲ့ Integrity ကို စစ်ဆေးဖို့ အသုံးပြုတဲ့ Cryptographic Fingerprint တစ်မျိုးပါ။
- Digital Ledger ဆိုတာ ငွေကြေး သို့မဟုတ် အခြား Transaction တွေကို Digital အဖြစ် မှတ်တမ်းတင်ထားတဲ့ စနစ်ပါ။

Blockchain ရဲ့ အရေးကြီးတဲ့ အချက်တစ်ခုက...

Transaction Record တွေကို Network ပေါ်မှာ အစီအစဉ်တကျ သိမ်းဆည်းပြီး စစ်ဆေးနိုင်အောင် ပြုလုပ်ထားခြင်း ဖြစ်ပါတယ်။ Bitcoin ရဲ့ Blockchain မှာ ပထမဆုံး Block ကို Genesis Block လို့ခေါ်ပါတယ်။ Genesis ဆိုတာ အစပြုခြင်း၊ ပထမဆုံးဖြစ်ခြင်းဆိုတဲ့ အဓိပ္ပာယ်ရှိပါတယ်။ ဒီ Genesis Block နဲ့အတူ Bitcoin ရဲ့ သမိုင်းအစပြုလာပါတယ်။ Bitcoin ကို ဖန်တီးခဲ့သူဟာ Satoshi Nakamoto ဆိုတဲ့ အမည်ကို အသုံးပြုခဲ့သူဖြစ်ပါတယ်။ သူဟာ လူတစ်ဦးလား၊ လူအုပ်စုတစ်ခုလားဆိုတာကို ယနေ့အထိ အတည်ပြုနိုင်ခြင်း မရှိသေးပါဘူး။ Satoshi ရဲ့ Bitcoin Whitepaper ကတော့ Bitcoin ရဲ့ ရည်ရွယ်ချက်နဲ့ အလုပ်လုပ်ပုံကို နားလည်ဖို့ အရေးကြီးတဲ့ Technical Document တစ်ခုဖြစ်ပါတယ်။

ကျွန်တော် Blockchain ကို နားလည်ဖို့ Cryptocurrency ကို အရင်ဆုံးမဟုတ်ဘဲ Ledger ဆိုတာဘာလဲ၊ Transaction Record ဆိုတာဘာလဲ၊ Data Integrity နဲ့ Trust ဆိုတာတွေကို အရင်နားလည်ဖို့ လိုအပ်တယ်ဆိုတာပါ။ နောက်ထပ်အရေးကြီးတာက Blockchain က Cryptocurrency အတွက်ပဲ အသုံးပြုတာမဟုတ်ပါဘူး။ Smart Contract၊ Supply Chain၊ Digital Identity နဲ့ Financial Settlement စတဲ့ နယ်ပယ်တွေမှာလည်း အသုံးချနိုင်တဲ့ Technology တစ်ခုဖြစ်ပါတယ်။

ဒါပေမယ့် Blockchain ဟာ ပြဿနာအားလုံးကို အလိုအလျောက် ဖြေရှင်းပေးနိုင်တဲ့ နည်းပညာမဟုတ်ပါဘူး။ Security၊ Scalability၊ Privacy၊ Regulation နဲ့ Transaction Cost စတဲ့ အချက်တွေကိုလည်း ထည့်သွင်းစဉ်းစားဖို့ လိုအပ်ပါတယ်။
