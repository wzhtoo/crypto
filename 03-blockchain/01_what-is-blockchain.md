## Blockchain ဆိုတာ ဘာလဲ၊ ဘာကြောင့် အရေးကြီးတာလဲ?

Crypto နဲ့ Blockchain အကြောင်း လေ့လာလာရင်း ကျွန်တော် ပိုပြီး စိတ်ဝင်စားလာတာက Bitcoin တစ်ခုတည်းမဟုတ်ဘဲ သူ့နောက်က Technology ဖြစ်တဲ့ Blockchain ပါ။ အရင်တုန်းက Blockchain ဆိုတာ Bitcoin နဲ့ အတူတူပဲလို့ ထင်ခဲ့ဖူးပါတယ်။ အခု လေ့လာကြည့်တော့ Bitcoin က Blockchain Technology ကို အသုံးပြုထားတဲ့ Application တစ်ခုဖြစ်ပြီး Blockchain ကိုယ်တိုင်ကတော့ ပိုမိုကျယ်ပြန့်တဲ့ Technology တစ်ခုဆိုတာ နားလည်လာပါတယ်။

### Blockchain ဆိုတာ ဘာလဲ?

အလွယ်ပြောရရင် Blockchain ဆိုတာ Transaction Data တွေကို Block တွေအဖြစ် စုစည်းပြီး အဲဒီ Block တွေကို Chain တစ်ခုလို ဆက်တိုက်ချိတ်ဆက်ထားတဲ့ Digital Ledger Technology ဖြစ်ပါတယ်။ ဗဟိုချုပ်ကိုင်ထားတဲ့ ငွေကြေးစနစ်မှာ ငွေစာရင်း Ledger ကို ဘဏ်တစ်ခုက ထိန်းချုပ်ထားနိုင်ပါတယ်။

Blockchain မှာတော့ Network ထဲက Computer အများအပြားက Transaction Record တွေကို စစ်ဆေးပြီး ထိန်းသိမ်းကြပါတယ်။

ဒီနေရာမှာ စိတ်ဝင်စားစရာကောင်းတာက...

**ယုံကြည်ရတဲ့ အဖွဲ့အစည်းတစ်ခုတည်းကို မမှီခိုဘဲ Data Record တွေကို ဘယ်လိုယုံကြည်နိုင်အောင် လုပ်မလဲ?** ဆိုတဲ့ ပြဿနာကို ဖြေရှင်းဖို့ ကြိုးစားထားတာပါ။

### Block နဲ့ Chain

Block တစ်ခုထဲမှာ Transaction Data တွေကို စုစည်းထားပါတယ်။

```text
Genesis Block
     ↓
Block 1
     ↓
Block 2
     ↓
Block 3
```

Block တစ်ခုနဲ့တစ်ခု ချိတ်ဆက်ထားတဲ့အတွက် အရင် Record တွေကို ပြောင်းလဲဖို့ ပိုမိုခက်ခဲလာပါတယ်။ ဒီစနစ်မှာ Hashing၊ Cryptography နဲ့ Consensus Mechanism တွေက အရေးကြီးတဲ့ အခန်းကဏ္ဍကနေ ပါဝင်ပါတယ်။

### Blockchain က ဘာကြောင့် တော်လှန်ပြောင်းလဲနိုင်တာလဲ?

Blockchain ရဲ့ အဓိကစိတ်ဝင်စားစရာက Decentralization ပါ။

ဗဟိုချုပ်ကိုင်ထားတဲ့ ငွေကြေးစနစ်ငွေလွှဲစနစ်မှာ...

```text
Person A
   ↓
Bank / Payment Provider
   ↓
Person B
```

ဆိုတဲ့ ကြားခံစနစ်ရှိပါတယ်။

Blockchain Network မှာတော့ အချို့သော Use Case တွေအတွက် Participant တွေအကြား တိုက်ရိုက် Value Transfer ပြုလုပ်နိုင်ပါတယ်။ ဒါကြောင့် အနာဂတ်မှာ Payment၊ Supply Chain၊ Digital Identity၊ Asset Ownership နဲ့ Contract Automation စတဲ့ နယ်ပယ်တွေမှာ အသုံးချနိုင်မယ့် အလားအလာရှိပါတယ်။

### Smart Contract ဆိုတာလည်း စိတ်ဝင်စားစရာကောင်းပါတယ်

Smart Contract ဆိုတာ Blockchain ပေါ်မှာ ရေးသားထားတဲ့ Program တစ်ခုဖြစ်ပါတယ်။ သတ်မှတ်ထားတဲ့ အခြေအနေတွေ ပြည့်စုံလာတဲ့အခါ Code အတိုင်း အလိုအလျောက် လုပ်ဆောင်နိုင်ပါတယ်။

ဥပမာ...

```text
IF Payment Received
AND Delivery Confirmed
THEN Release Funds
```

ဒါပေမယ့် Smart Contract က အမြဲတမ်း အပြည့်အဝ လုံခြုံတယ်လို့ မဆိုနိုင်ပါဘူး။ Code Bug၊ Oracle Problem၊ Private Key Theft နဲ့ Legal Enforcement စတဲ့ ပြဿနာတွေ ရှိနိုင်ပါတယ်။

### Bitcoin ကို ဘာကြောင့် ဖန်တီးခဲ့တာလဲ?

Blockchain ကို နားလည်လာတဲ့အခါ Bitcoin ရဲ့ ရည်ရွယ်ချက်ကိုလည်း ပိုပြီး နားလည်လာနိုင်ပါတယ်။ Bitcoin ရဲ့ အဓိကအယူအဆက Trusted Third Party တစ်ခုတည်းကို မမှီခိုဘဲ Digital Value ကို Peer-to-Peer ပုံစံနဲ့ လွှဲပြောင်းနိုင်တဲ့ စနစ်တစ်ခု ဖန်တီးဖို့ ဖြစ်ပါတယ်။

ဒီအယူအဆက 2008 Financial Crisis နောက်ပိုင်းမှာ ပိုပြီး စိတ်ဝင်စားစရာကောင်းလာခဲ့ပါတယ်။

### Genesis Block နဲ့ Satoshi Nakamoto

Blockchain တစ်ခုရဲ့ ပထမဆုံး Block ကို Genesis Block လို့ ခေါ်ပါတယ်။ Bitcoin ရဲ့ Genesis Block ကတော့ Bitcoin Blockchain ရဲ့ အစဖြစ်ပါတယ်။ Bitcoin ကို စတင်ဖန်တီးခဲ့သူဟာ Satoshi Nakamoto ဆိုတဲ့ အမည်ဝှက်အသုံးပြုသူ ဖြစ်ပါတယ်။

ဒါပေမယ့် Satoshi Nakamoto ရဲ့ အမှန်တကယ် Identity ကို အခုအချိန်အထိ သေချာမသိရသေးပါဘူး။ သူဟာ လူတစ်ဦးလား၊ အဖွဲ့တစ်ဖွဲ့လားဆိုတာလည်း အတည်ပြုထားခြင်း မရှိသေးပါဘူး။

### ကျွန်တော် နားလည်မိတဲ့ အချက်

Blockchain ကို လေ့လာတဲ့အခါ Bitcoin Price တက်မတက်ဆိုတာထက် နည်းပညာရဲ့ အခြေခံအယူအဆကို နားလည်ဖို့ ပိုအရေးကြီးတယ်လို့ ခံစားမိပါတယ်။

အခုအချိန်မှာ Blockchain ကို အသုံးပြုနိုင်မယ့် နယ်ပယ်တွေက...

- Cryptocurrency
- Smart Contracts
- Supply Chain
- Digital Identity
- Asset Tokenization
- Financial Settlement စတာတွေအထိ ကျယ်ပြန့်လာပါတယ်။

ဒါပေမယ့် Blockchain က ပြဿနာအားလုံးကို ဖြေရှင်းပေးနိုင်တဲ့ Magic Technology တစ်ခုတော့ မဟုတ်ပါဘူး။ Decentralization၊ Security၊ Scalability၊ Privacy နဲ့ Regulation တွေကြားမှာ Trade-off တွေလည်းရှိပါတယ်။

ကျွန်တော်အနေနဲ့တော့ Blockchain ကို “Crypto ရဲ့ နောက်က Technology” လို့ပဲ မမြင်တော့ဘဲ ယုံကြည်မှု၊ Data Ownership နဲ့ Digital Transactions တွေကို ဘယ်လိုပြန်လည်စဉ်းစားနိုင်မလဲဆိုတဲ့ Technology တစ်ခုအဖြစ် စတင်နားလည်လာပါတယ်။

ဒီအကြောင်းအရာကို ကိုယ်တိုင်လေ့လာပြီး နားလည်မိသလောက် ပြန်လည်မျှဝေလိုက်ပါတယ်။
