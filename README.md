## Repo အကြောင်း

ဒါက **Myanmar Bitcoin Group** အတွက် ဖန်တီးထားတဲ့ open-source ခရစ်တိုငွေကြေး သင်တန်းပါ။
IT/Web Developer တွေအတွက် အထူးသင့်လျော်ပါတယ်။

## ဘာတွေ သင်ရမလဲ

- ခရစ်တိုငွေကြေး အခြေခံ
- Bitcoin နဲ့ Blockchain
- Wallet နဲ့ Security
- Exchange နဲ့ Trading
- Smart Contract နဲ့ DeFi
- Portfolio Management
