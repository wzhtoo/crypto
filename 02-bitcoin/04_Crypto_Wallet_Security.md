ဒီပို့စ်ရဲ့ ရည်ရွယ်ချက်က Cryptocurrency ကို ဝယ်ယူဖို့၊ ရင်းနှီးမြှုပ်နှံဖို့ တိုက်တွန်းတာမဟုတ်ဘဲ **Wallet Security အခြေခံသဘောတရားတွေကို လေ့လာမျှဝေခြင်း** ဖြစ်ပါတယ်။

## Crypto Wallet Security ကို လေ့လာရင်း နားလည်လာတဲ့ အချက်များ

မကြာသေးခင်က Cryptocurrency Security နဲ့ပတ်သက်တဲ့ Course တစ်ခုကို လေ့လာရင်း Paper Wallet, Public Address, Private Key, Hot Wallet နဲ့ Cold Wallet ဆိုတဲ့ အကြောင်းအရာတွေကို စိတ်ဝင်စားစရာကောင်းစွာ တွေ့ရှိခဲ့ပါတယ်။

အစပိုင်းမှာ Wallet ဆိုတာ Cryptocurrency တွေကို ထည့်သိမ်းထားတဲ့ Digital ပိုက်ဆံအိတ်တစ်ခုလိုပဲ ထင်ခဲ့ပါတယ်။ ဒါပေမယ့် ဆက်လေ့လာကြည့်တဲ့အခါ Wallet ထဲမှာ Coin တွေကို တကယ်သိမ်းထားတာမဟုတ်ဘဲ Blockchain ပေါ်မှာ ရှိတဲ့ ပိုင်ဆိုင်မှုတွေကို အသုံးပြုနိုင်ဖို့ လိုအပ်တဲ့ Key တွေကို စီမံခန့်ခွဲပေးတဲ့ Software သို့မဟုတ် Hardware ဖြစ်တယ်ဆိုတာ နားလည်လာပါတယ်။

### Public Address နဲ့ Private Key

Crypto Wallet Security မှာ အရေးကြီးဆုံး အချက်တွေထဲက တစ်ခုက Public Address နဲ့ Private Key ကို ခွဲခြားနားလည်ဖို့ ဖြစ်ပါတယ်။

**Public Address** က ငွေလက်ခံဖို့ အသုံးပြုတဲ့ လိပ်စာတစ်ခုလို ဖြစ်ပါတယ်။ တခြားသူတွေကို ပေးလို့ရပြီး ကိုယ့်ဆီကို Cryptocurrency ပို့ပေးဖို့ အသုံးပြုနိုင်ပါတယ်။

**Private Key** ကတော့ ကိုယ့်ရဲ့ ပိုင်ဆိုင်မှုကို အသုံးပြုနိုင်ဖို့ လိုအပ်တဲ့ လျှို့ဝှက်သော Key ဖြစ်ပါတယ်။ Private Key ကို သိရှိသူတစ်ယောက်က Wallet ထဲက ပိုင်ဆိုင်မှုတွေကို အသုံးပြုနိုင်တဲ့အတွက် ဘယ်သူ့ကိုမှ မျှဝေသင့်ပါဘူး။

ဒါကြောင့် မှတ်ထားသင့်တာက...

- Public Address ကို မျှဝေလို့ရတယ်။
- Private Key ကို မျှဝေလို့မရဘူး။
- Public Address သိရုံနဲ့ Private Key ကို ပြန်တွက်ထုတ်လို့ မရဘူး။
- Private Key ပျောက်ဆုံးသွားရင် Wallet ထဲက ပိုင်ဆိုင်မှုတွေကို ပြန်လည်အသုံးပြုဖို့ အခက်အခဲရှိနိုင်တယ်။

### Hot Wallet နဲ့ Cold Wallet

နောက်ထပ် စိတ်ဝင်စားစရာကောင်းတဲ့ အကြောင်းအရာက Hot Wallet နဲ့ Cold Wallet ဖြစ်ပါတယ်။

**Hot Wallet** ဆိုတာ Internet နဲ့ ချိတ်ဆက်အသုံးပြုနေတဲ့ Wallet ဖြစ်ပါတယ်။ ဖုန်း၊ Computer သို့မဟုတ် Browser Extension တွေမှာ အသုံးပြုတဲ့ Wallet အများစုက Hot Wallet အမျိုးအစားထဲမှာ ပါဝင်ပါတယ်။

အားသာချက်က အသုံးပြုရလွယ်ကူပြီး ငွေလွှဲတာ၊ လက်ခံတာတွေကို လျင်မြန်စွာ လုပ်နိုင်ပါတယ်။ ဒါပေမယ့် Internet နဲ့ ချိတ်ဆက်ထားတာကြောင့် Malware, Phishing, Hacking နဲ့ အခြားသော Online Attack တွေကို သတိထားရပါတယ်။

**Cold Wallet** ဆိုတာ Private Key သို့မဟုတ် Signing Key တွေကို Internet နဲ့ တိုက်ရိုက်မချိတ်ဆက်ထားတဲ့ ပတ်ဝန်းကျင်မှာ ထိန်းသိမ်းထားခြင်း ဖြစ်ပါတယ်။

Paper Wallet နဲ့ Hardware Wallet တွေကို Cold Storage နည်းလမ်းအဖြစ် အသုံးပြုနိုင်ပါတယ်။ သို့သော် Cold Storage ဖြစ်တယ်ဆိုတာနဲ့ အလိုအလျောက် လုံခြုံသွားတာ မဟုတ်ပါဘူး။ Private Key ကို ဘယ်လိုထုတ်လုပ်ထားသလဲ၊ ဘယ်လို Backup လုပ်ထားသလဲ၊ ဘယ်သူတွေက ရယူနိုင်သလဲဆိုတာတွေကလည်း အရေးကြီးပါတယ်။

### Paper Wallet ဆိုတာ ဘာလဲ

Paper Wallet ဆိုတာ Public Address နဲ့ Private Key ကို စာရွက်ပေါ်မှာ Print ထုတ်ပြီး Offline အဖြစ် သိမ်းဆည်းထားတဲ့ နည်းလမ်းတစ်ခု ဖြစ်ပါတယ်။

သဘောတရားအရ Internet မချိတ်ထားတဲ့အတွက် Online Attack အချို့ကို လျှော့ချနိုင်ပါတယ်။ ဒါပေမယ့် စာရွက်ပျောက်သွားတာ၊ မီးလောင်တာ၊ ရေစိုတာ၊ တခြားသူတွေတွေ့သွားတာမျိုး ဖြစ်နိုင်တဲ့အတွက် အန္တရာယ်မရှိဘူးလို့ မဆိုနိုင်ပါဘူး။

အထူးသဖြင့် Paper Wallet ကို Online Website တစ်ခုမှာ Generate လုပ်ပြီး Private Key ကို တိုက်ရိုက်ဖန်တီးတာမျိုးကို သတိထားရပါတယ်။ Website ရဲ့ Code, Random Number Generation နဲ့ Environment ကို မယုံကြည်နိုင်ရင် Private Key လုံခြုံမှုကို အာမခံလို့ မရပါဘူး။

Course ထဲမှာတော့ Wallet Generator ကို Local Computer ပေါ်မှာ အသုံးပြုဖို့၊ Source Code ကို လေ့လာဖို့နဲ့ Internet ကနေ ခွဲထားတဲ့ Environment မှာ Key ထုတ်လုပ်ဖို့ အကြံပြုထားပါတယ်။ ဒါပေမယ့် Local HTML File တစ်ခုကို Run လုပ်လိုက်ရုံနဲ့ လုံခြုံမှု အပြည့်အဝ ရရှိတယ်လို့တော့ မယူဆသင့်ပါဘူး။

### USB ထဲမှာ Private Key သိမ်းထားရင် လုံခြုံပြီလား

ဒီအပိုင်းကလည်း ကျွန်တော်အတွက် အရေးကြီးတဲ့ သင်ခန်းစာတစ်ခု ဖြစ်ပါတယ်။

Private Key ကို USB Drive ထဲမှာ သိမ်းထားတာဟာ စာရွက်ပေါ်မှာ ရေးထားတာထက် ပိုလုံခြုံမယ်လို့ တစ်ခါတလေ ထင်တတ်ကြပါတယ်။ ဒါပေမယ့် USB Drive ပျောက်သွားနိုင်ပါတယ်၊ Malware ပါတဲ့ Computer မှာ ချိတ်မိနိုင်ပါတယ်၊ File ကို Copy ကူးသွားနိုင်ပါတယ်။

Encrypted USB Device, Fingerprint Security Device စတဲ့ Hardware တွေက လုံခြုံမှုကို တိုးမြှင့်ပေးနိုင်ပေမယ့် Device တစ်ခုရှိရုံနဲ့ လုံခြုံရေးပြည့်စုံသွားတာ မဟုတ်ပါဘူး။

အရေးကြီးဆုံးက...

- Private Key ကို Screenshot မရိုက်ထားသင့်ပါ။
- Cloud Storage ထဲ မတင်သင့်ပါ။
- Email, Messenger, Telegram စတဲ့ Online Communication ထဲ မပို့သင့်ပါ။
- Word File, Text File, အလွယ်တကူဖွင့်နိုင်တဲ့ File တွေထဲမှာ မသိမ်းသင့်ပါ။
- Backup လုပ်ထားရင်လည်း ဘယ်နေရာမှာ ဘယ်သူတွေ ရယူနိုင်သလဲဆိုတာ စဉ်းစားထားသင့်ပါတယ်။

### 2FA က ဘာအတွက်လဲ

2FA (Two-Factor Authentication) က Exchange Account, Email Account စတဲ့ Online Account တွေရဲ့ လုံခြုံရေးကို မြှင့်တင်ပေးနိုင်ပါတယ်။

Password တစ်ခုတည်းနဲ့ Login ဝင်လို့မရအောင် ဒုတိယအဆင့် Verification ထပ်မံလိုအပ်စေပါတယ်။

ဒါပေမယ့် 2FA ရှိတယ်ဆိုတာ Private Key ကို ကာကွယ်ပေးတယ်လို့ တိုက်ရိုက်မဆိုနိုင်ပါဘူး။ ကိုယ့်ရဲ့ Private Key သို့မဟုတ် Seed Phrase ကို တခြားသူထံ မျှဝေမိရင် 2FA ရှိနေရုံနဲ့ ပြန်ကာကွယ်ပေးနိုင်မှာ မဟုတ်ပါဘူး။

### Blockchain Explorer က ဘာတွေမြင်နိုင်လဲ

Course ထဲမှာ Blockchain Explorer ကို အသုံးပြုပြီး Transaction တွေကို စောင့်ကြည့်တဲ့ Demonstration တစ်ခုလည်း ပါဝင်ပါတယ်။

Blockchain Explorer က Wallet Address ရဲ့ Transaction History, ငွေလွှဲဝင်ငွေလွှဲထွက်မှုနဲ့ Blockchain ပေါ်မှာ မှတ်တမ်းတင်ထားတဲ့ အချက်အလက်တွေကို ကြည့်ရှုနိုင်စေပါတယ်။

ဒါပေမယ့် Public Transaction Information ကို မြင်နိုင်တာနဲ့ Private Key ကို သိနိုင်တာ မတူပါဘူး။

Blockchain ရဲ့ အဓိက သဘောတရားတစ်ခုက Transaction တွေကို Public ဖြစ်အောင် မှတ်တမ်းတင်ထားနိုင်ပေမယ့် Private Key ကိုတော့ လျှို့ဝှက်ထားရခြင်း ဖြစ်ပါတယ်။

## ကျွန်တော် နားလည်လာတဲ့ အဓိကသင်ခန်းစာများ

ဒီအကြောင်းအရာတွေကို လေ့လာပြီးနောက် Cryptocurrency Security ဆိုတာ Wallet တစ်ခု Download လုပ်ပြီး Password တပ်ထားရုံနဲ့ မပြီးဆုံးဘူးဆိုတာ နားလည်လာပါတယ်။

Security ဆိုတာ...

**Understand → Verify → Secure → Practice**

ဆိုတဲ့ လုပ်ငန်းစဉ်တစ်ခုလို ဖြစ်ပါတယ်။

1. ကိုယ်အသုံးပြုမယ့် Wallet နဲ့ Network ကို နားလည်ပါ။
2. Address, Private Key, Seed Phrase တွေကို သေချာစစ်ဆေးပါ။
3. Private Information တွေကို Online ပေါ် မပေါက်ကြားအောင် ထိန်းသိမ်းပါ။
4. လက်တွေ့လေ့လာတဲ့အခါ အစစ်အမှန် ငွေကြေးမသုံးမီ Testnet သို့မဟုတ် အန္တရာယ်နည်းတဲ့ ပတ်ဝန်းကျင်မှာ လေ့ကျင့်ပါ။

ကျွန်တော်ကလည်း ဒီအကြောင်းအရာတွေကို လေ့လာနေဆဲ Beginner တစ်ယောက်ဖြစ်ပါတယ်။ သိလာသမျှကို ကိုယ်တိုင်စမ်းသပ်နားလည်ပြီး မိတ်ဆွေများကို ပြန်လည်မျှဝေခြင်းဖြစ်ပါတယ်။

**Cryptocurrency ကို အသုံးပြုမယ်ဆိုရင် အမြတ်ရဖို့ထက် လုံခြုံရေးကို အရင်နားလည်ထားဖို့ ပိုအရေးကြီးပါတယ်။**
