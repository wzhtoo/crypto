# 03 - Cryptocurrency Security

ဒီနေ့ Cryptocurrency Security အကြောင်း ဆက်လက်လေ့လာဖြစ်ပါတယ်။

အရင်ကတော့ Crypto Wallet လုံခြုံရေးဆိုရင် Password ကောင်းကောင်းထားရုံ၊ Wallet တစ်ခုသုံးရုံလောက်နဲ့ လုံလောက်မယ်လို့ ထင်ခဲ့ပါတယ်။ ဒါပေမဲ့ လေ့လာကြည့်ရင်း Security ဆိုတာ အဲဒီထက်ပိုပြီး ကျယ်ပြန့်တယ်ဆိုတာ နားလည်လာပါတယ်။

အရေးကြီးတဲ့အချက်တစ်ခုက Password Security ပါ။

Password တစ်ခုကို ရှည်လျားပြီး ခန့်မှန်းရခက်အောင် ဖန်တီးဖို့လိုပါတယ်။ Uppercase, Lowercase, Numbers နဲ့ Special Characters တွေ အသုံးပြုနိုင်ပါတယ်။ ဒါပေမဲ့ Character တွေ ရောစပ်ထားရုံနဲ့ မပြီးသေးပါဘူး။ Password က Unique ဖြစ်ဖို့၊ Website တစ်ခုမှာသုံးတဲ့ Password ကို အခြား Website တွေမှာ ပြန်မသုံးဖို့လည်း အရေးကြီးပါတယ်။

နောက်တစ်ခုက Hashing နဲ့ Encryption ကွာခြားချက်ပါ။

SHA-256 ကို လေ့လာရင်း Hashing ဆိုတာ Data ကို Fixed-Length Output အဖြစ် ပြောင်းပေးတဲ့ Cryptographic Function တစ်ခုဖြစ်ပြီး Encryption နဲ့ မတူဘူးဆိုတာ သိလာပါတယ်။ အရင်က Hash နဲ့ Encryption ကို တစ်မျိုးတည်းလို နားလည်ထားမိပေမယ့် အခုတော့ သူတို့ရဲ့ ရည်ရွယ်ချက်နဲ့ အသုံးပြုပုံ မတူဘူးဆိုတာ ပိုရှင်းလာပါတယ်။

Cryptocurrency Wallet Security မှာလည်း Public Address နဲ့ Private Key က အလွန်အရေးကြီးပါတယ်။

Public Address ကို ငွေလက်ခံဖို့ အသုံးပြုနိုင်ပေမယ့် Private Key နဲ့ Seed Phrase ကတော့ လျှို့ဝှက်ထားရမယ့် အချက်အလက်တွေ ဖြစ်ပါတယ်။ Private Key ကို တခြားသူတစ်ယောက် သိသွားရင် Wallet ထဲက ငွေကြေးတွေကို အန္တရာယ်ရှိနိုင်ပါတယ်။

Hot Wallet နဲ့ Cold Wallet ကွာခြားချက်ကိုလည်း ဒီသင်ခန်းစာမှာ ဆက်စပ်နားလည်လာပါတယ်။

Hot Wallet တွေက နေ့စဉ်အသုံးပြုရလွယ်ကူပေမယ့် Internet နဲ့ ချိတ်ဆက်ထားတဲ့အတွက် Phishing, Malware နဲ့ အခြား Online Attack တွေကို သတိထားဖို့လိုပါတယ်။

Cold Wallet တွေက Private Key ကို Offline ထားနိုင်တဲ့အတွက် Online Attack အချို့ကို လျှော့ချနိုင်ပေမယ့် Backup မမှန်ကန်ရင် ကိုယ်တိုင်ပဲ Wallet Access ဆုံးရှုံးနိုင်ပါတယ်။

ဒီအရာတွေကို လေ့လာရင်း ကျွန်တော် သဘောပေါက်လာတာက...

**Secure Today ဆိုတာ Secure Forever မဟုတ်ဘူး** ဆိုတဲ့အချက်ပါ။

ယနေ့အသုံးပြုနေတဲ့ Security Protocol တွေဟာ အနာဂတ်မှာ အားနည်းလာနိုင်ပါတယ်။ ဒါကြောင့် Cryptocurrency Security ကို လေ့လာတဲ့အခါ Algorithm တစ်ခုကို ယုံကြည်ပြီး ရပ်မနေဘဲ နောက်ဆုံးပေါ် Security Research, Vulnerability နဲ့ Best Practices တွေကို ဆက်လက်လေ့လာနေဖို့ လိုအပ်ပါတယ်။

နောက်ထပ် စိတ်ဝင်စားစရာကောင်းတဲ့ အယူအဆတစ်ခုက **Think Like a Hacker** ဆိုတာပါ။

ဒါဟာ မကောင်းတဲ့အရာလုပ်ဖို့ သင်ယူတာမဟုတ်ပါဘူး။ Security ကို ကာကွယ်ချင်ရင် တိုက်ခိုက်သူဘက်က ဘယ်လိုစဉ်းစားနိုင်မလဲဆိုတာကို နားလည်ထားဖို့လိုတယ်လို့ ဆိုလိုတာပါ။

အိမ်တစ်လုံးမှာ Lock, Alarm, CCTV တွေရှိပေမယ့် Window တစ်ခုပွင့်နေခဲ့ရင် Security အားနည်းနိုင်သလို Crypto Wallet မှာလည်း Strong Password ရှိပေမယ့် Seed Phrase ကို မလုံခြုံတဲ့နေရာမှာ ထည့်လိုက်ရင် အန္တရာယ်ဖြစ်နိုင်ပါတယ်။

ဒီနေ့လေ့လာရတဲ့အကြောင်းအရာတွေက Cryptocurrency ကို ဝယ်ယူခြင်းထက် ပိုအရေးကြီးတဲ့ အခြေခံ Security Concept တွေကို နားလည်စေပါတယ်။

ကျွန်တော်က Beginner တစ်ယောက်အနေနဲ့ လေ့လာထားသလောက်ကို မျှဝေပေးတာဖြစ်ပါတယ်။ အားလုံးလည်း ကိုယ်တိုင်လေ့လာ၊ ကိုယ်တိုင်စစ်ဆေးပြီး Cryptocurrency Security ကို ပိုမိုနားလည်လာနိုင်ကြပါစေ။

**Learn → Verify → Secure → Understand → Share**
