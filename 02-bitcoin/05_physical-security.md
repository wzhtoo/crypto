# Physical Security

## Crypto Security မှာ Physical Security ကိုလည်း မမေ့သင့်ပါ

Cryptocurrency Security ဆိုရင် Password, Private Key, Seed Phrase, Two-Factor Authentication စတဲ့ Digital Security အကြောင်းတွေကို အများအားဖြင့် စဉ်းစားတတ်ကြပါတယ်။

ဒါပေမယ့် Course တစ်ခုကို လေ့လာရင်း ကျွန်တော် သတိထားမိတဲ့ အချက်တစ်ခုကတော့ **Digital Security တစ်ခုတည်းနဲ့ မလုံလောက်ဘဲ Physical Security ကိုလည်း ထည့်သွင်းစဉ်းစားဖို့ လိုအပ်တယ်** ဆိုတာပါ။

Cryptocurrency ကို ကိုယ်တိုင်သိမ်းဆည်းအသုံးပြုတဲ့အခါ အရေးကြီးဆုံးအရာတွေထဲမှာ Private Key, Seed Phrase, Hardware Wallet နဲ့ Backup Information တွေ ပါဝင်ပါတယ်။ ဒီအရာတွေကို ဘယ်နေရာမှာ သိမ်းထားသလဲဆိုတာကလည်း ကိုယ့်ရဲ့ Security နဲ့ တိုက်ရိုက်ဆက်စပ်နေပါတယ်။

### Physical Storage ဆိုတာဘာလဲ

အဓိကရည်ရွယ်ချက်ကတော့ အဖိုးတန်ပစ္စည်းတွေကို အလွယ်တကူ မမြင်နိုင်အောင် ဖုံးကွယ်ထားခြင်း ဖြစ်ပါတယ်။

ဒါပေမယ့် ကျွန်တော်နားလည်လာတာက...

**ဖုံးကွယ်ထားခြင်းနဲ့ လုံခြုံစွာ ကာကွယ်ထားခြင်းဟာ တူညီတာမဟုတ်ပါဘူး။**

စာအုပ်တစ်အုပ်လို ဖုံးကွယ်ထားနိုင်ပေမယ့် တစ်စုံတစ်ယောက်က သိရှိသွားရင် အဲဒီပစ္စည်းတစ်ခုလုံးကို ယူဆောင်သွားနိုင်ပါတယ်။ ဒါကြောင့် Concealment ကို Security ရဲ့ အစိတ်အပိုင်းတစ်ခုအဖြစ်သာ စဉ်းစားသင့်ပြီး တစ်ခုတည်းသော ကာကွယ်ရေးနည်းလမ်းအဖြစ် မမှီခိုသင့်ပါဘူး။

### Safe ရှိရုံနဲ့ မလုံလောက်ပါ

Safe တစ်ခု ဝယ်ထားရုံနဲ့ လုံခြုံမှု အပြည့်အဝ ရရှိသွားတာ မဟုတ်ပါဘူး။

Safe သေးသေးလေးဖြစ်ရင် တစ်စုံတစ်ယောက်က Safe တစ်ခုလုံးကို ယူဆောင်သွားနိုင်ပါတယ်။ ဒါကြောင့် Safe ကို Floor ဒါမှမဟုတ် Wall မှာ Bolt လုပ်ထားနိုင်ခြင်းက အရေးကြီးပါတယ်။

Physical Security မှာ Lock ကောင်းတာတစ်ခုတည်း မဟုတ်ဘဲ...

- Safe ကို ဘယ်လိုတပ်ဆင်ထားသလဲ။
- ဘယ်သူတွေ သိရှိထားသလဲ။
- ဘယ်နေရာမှာ ထားထားသလဲ။
- ပျောက်ဆုံးသွားရင် ဘယ်လိုပြန်လည်ရယူမလဲ။

ဆိုတဲ့အချက်တွေကိုပါ စဉ်းစားသင့်ပါတယ်။

### Private Key ကို ဘယ်လိုကာကွယ်မလဲ

Cryptocurrency ဟာ Safe ထဲမှာ တိုက်ရိုက်ထည့်သိမ်းထားတဲ့ ပစ္စည်းမဟုတ်ပါဘူး။ Blockchain ပေါ်မှာ မှတ်တမ်းတင်ထားတဲ့ Digital Asset ကို အသုံးပြုနိုင်ဖို့ Private Key နဲ့ Wallet Information တွေကို ထိန်းသိမ်းထားရတာ ဖြစ်ပါတယ်။

ဒါကြောင့် Physical Storage မှာ သိမ်းထားရမယ့်အရာတွေက...

- Seed Phrase
- Private Key Backup
- Hardware Wallet
- Recovery Information

စတဲ့ အချက်အလက်တွေ ဖြစ်ပါတယ်။

ဒီအချက်တွေကို တစ်စုံတစ်ယောက်က ရရှိသွားရင် ကိုယ့်ရဲ့ Digital Asset တွေကို အသုံးပြုနိုင်တဲ့ အန္တရာယ်ရှိနိုင်တာကြောင့် လုံခြုံစွာ သိမ်းဆည်းထားဖို့ လိုအပ်ပါတယ်။

### Webcam Cover လေးတစ်ခုရဲ့ အရေးပါမှု

Laptop, iPad, Tablet နဲ့ Computer တွေရဲ့ Webcam ပေါ်မှာ ဖွင့်ပိတ်နိုင်တဲ့ Cover သေးသေးလေးတစ်ခု တပ်ထားခြင်းက Privacy အတွက် အထောက်အကူဖြစ်နိုင်ပါတယ်။

အထူးသဖြင့် Desk ပေါ်မှာ Private Key, Seed Phrase, QR Code ဒါမှမဟုတ် အခြား Sensitive Information တွေကို ဖွင့်ထားခဲ့ရင် Webcam ကို ခွင့်ပြုချက်မရှိဘဲ အသုံးပြုနိုင်တဲ့ အန္တရာယ်ကိုလည်း စဉ်းစားသင့်ပါတယ်။

Webcam Cover က Security ပြဿနာအားလုံးကို ဖြေရှင်းပေးနိုင်တာ မဟုတ်ပေမယ့် Privacy Protection အတွက် ရိုးရှင်းပြီး အသုံးဝင်တဲ့ Security Layer တစ်ခု ဖြစ်ပါတယ်။

## ကျွန်တော် နားလည်လာတဲ့ အဓိကသင်ခန်းစာ

Cybersecurity ဆိုတာ Digital System တစ်ခုတည်းကို ကာကွယ်တာမဟုတ်ပါဘူး။

ကိုယ့်ရဲ့ Data, Device, Account, Private Information နဲ့ Physical Environment အားလုံးကို ထည့်သွင်းစဉ်းစားရတဲ့ အရာဖြစ်ပါတယ်။

Cryptocurrency Security မှာလည်း...

**Digital Security + Physical Security + Operational Security**

ဆိုတဲ့ အစိတ်အပိုင်းသုံးခုကို တွဲဖက်စဉ်းစားဖို့ လိုအပ်ပါတယ်။

ကျွန်တော်ကလည်း ဒီအကြောင်းအရာတွေကို လေ့လာနေဆဲ Beginner တစ်ယောက်ဖြစ်ပါတယ်။ လေ့လာရင်း သိလာသမျှကို ကိုယ်တိုင်နားလည်အောင် ပြန်လည်စဉ်းစားပြီး မျှဝေခြင်း ဖြစ်ပါတယ်။

**Crypto Security ကို လေ့လာတဲ့အခါ Digital World ကိုသာ မကြည့်ဘဲ Physical World ကိုပါ မမေ့သင့်ပါဘူး။**

**Understand → Protect → Verify → Secure**
