# Crypto Security Fundamentals: Wallets & Private Keys

Crypto ကို ဆက်ပြီးလေ့လာရင်း အခု Security နဲ့ Wallet အပိုင်းကို စတင်ရောက်လာပါတယ်။ ဒီ Group ထဲမှာ Web Developer တွေ၊ IT သမားတွေ အများကြီးရှိတာကြောင့် အောက်မှာရေးမယ့်အကြောင်းအရာတွေက အများစုအတွက် အသစ်အဆန်းတော့ မဟုတ်ပါဘူး။

ဒါပေမယ့် ကျွန်တော်ကိုယ်တိုင် Crypto ကို စနစ်တကျ လေ့လာနေတဲ့အတွက် လေ့လာရင်း သိလာတာတွေကို ဒီမှာ ပြန်မျှဝေထားချင်ပါတယ်။

ဒီအပိုင်းမှာ အဓိကလေ့လာရမယ့်အရာတွေကတော့ -

• Security နဲ့ Wallet

Crypto မှာ Wallet ဆိုတာ ဘာလဲ၊ Asset တွေကို ဘယ်လိုထိန်းချုပ်ထားသလဲဆိုတာကနေ စပြီး လေ့လာရပါတယ်။

• Private Key

Crypto Security မှာ အရေးကြီးဆုံး Concept တွေထဲက တစ်ခုပါ။

Private Key ကို ထိန်းချုပ်နိုင်မှုက ကိုယ့်ရဲ့ Crypto Asset ကို ထိန်းချုပ်နိုင်မှုနဲ့ တိုက်ရိုက်ဆက်စပ်နေပါတယ်။ ဒါကြောင့် Private Key ကို ဘာကြောင့် အလွန်အရေးကြီးတယ်လို့ ပြောကြတာလဲဆိုတာကို နားလည်ဖို့လိုပါတယ်။

• Public Key

Private Key နဲ့ ဆက်နွယ်နေတဲ့ Public Key အကြောင်းကိုလည်း လေ့လာရပါတယ်။ Public Key နဲ့ Private Key ရဲ့ ဆက်နွယ်မှုက Cryptography ရဲ့ အခြေခံ Concept တွေထဲက တစ်ခုဖြစ်ပါတယ်။

• Hashing

နောက်ထပ် အရေးကြီးတာက Hashing ပါ။ အထူးသဖြင့် SHA-1 နဲ့ SHA-256 တို့ကို လေ့လာပြီး Hashing ဆိုတာ ဘယ်လိုအလုပ်လုပ်သလဲဆိုတာကို နားလည်အောင် လေ့လာရမှာဖြစ်ပါတယ်။ SHA-256 ကတော့ Bitcoin ရဲ့ Security နဲ့ ဆက်စပ်နေတဲ့ အရေးကြီးတဲ့ Cryptographic Algorithm တစ်ခုဖြစ်တာကြောင့် ဒီအပိုင်းကို သေချာနားလည်ချင်ပါတယ်။

• Hot Storage နဲ့ Cold Storage

Crypto Asset တွေကို ဘယ်လို Storage လုပ်ထားသလဲဆိုတာလည်း အရေးကြီးပါတယ်။ Hot Storage နဲ့ Cold Storage ဆိုတာ ဘာလဲ၊ Security ပိုင်းမှာ ဘာတွေကွာခြားသလဲဆိုတာကို ဆက်လေ့လာရမှာပါ။ ဒီအပိုင်းမှာ ကျွန်တော်အတွက် အထူးစိတ်ဝင်စားစရာကောင်းတာက Security ကို အစောပိုင်းကတည်းက ထည့်ပြီး လေ့လာတာပါ။

Crypto ကို ငွေကြေးတစ်ခုအနေနဲ့ပဲ ကြည့်မယ်ဆိုရင် Buy, Sell, Price တက်ကျတာတွေကိုပဲ အာရုံစိုက်မိနိုင်ပါတယ်။

ဒါပေမယ့် နည်းပညာဘက်က ကြည့်မယ်ဆိုရင် -

### Cryptography

- → Keys
- → Hashing
- → Wallet
- → Storage
- → Security

ဆိုတဲ့ အခြေခံ Concept တွေကို နားလည်ဖို့လိုလာပါတယ်။

Web Development လေ့လာဖူးသူတွေအတွက် Hashing, Encryption, Keys စတဲ့ Terms တွေက သိပြီးသားဖြစ်နိုင်ပါတယ်။

ဒါပေမယ့် Crypto ထဲမှာ ဒီ Concepts တွေကို ဘယ်လိုအသုံးချထားသလဲဆိုတာကို ပြန်ပြီးချိတ်ဆက်လေ့လာရတာက ကျွန်တော့်အတွက်တော့ စိတ်ဝင်စားစရာကောင်းပါတယ်။

နောက်ပိုင်းမှာ Theory တင်မဟုတ်ဘဲ Public Key, Private Key, Hashing တွေကို လက်တွေ့စမ်းသပ်ပြီး Paper-based QR Wallet တစ်ခုကိုပါ ပြုလုပ်ကြည့်မယ့် အပိုင်းတွေ ပါလာမှာဖြစ်ပါတယ်။

Crypto ကို လေ့လာတဲ့အခါ Price ကိုပဲ လိုက်ကြည့်တာထက် နောက်ကွယ်က Technology နဲ့ Security ကိုပါ နားလည်အောင် လေ့လာသွားချင်ပါတယ်။
