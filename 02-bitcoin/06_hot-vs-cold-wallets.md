## Hot Wallet နဲ့ Cold Wallet ကို ဘယ်လိုအသုံးပြုသင့်လဲ

Cryptocurrency Security အခြေခံတွေကို လေ့လာပြီးတဲ့နောက် Wallet အမျိုးအစားတွေကို ပိုမိုအသေးစိတ် လေ့လာဖြစ်ပါတယ်။

Wallet ဆိုတာ Cryptocurrency တွေကို သိမ်းထားတဲ့ Digital ပိုက်ဆံအိတ်တစ်ခုလိုပဲ ထင်ခဲ့ပေမယ့် ဆက်လေ့လာကြည့်တဲ့အခါ Wallet ရွေးချယ်မှု၊ Private Key ကို ဘယ်သူထိန်းချုပ်ထားသလဲ၊ Internet နဲ့ ချိတ်ဆက်ထားသလားဆိုတာတွေက Security အတွက် အလွန်အရေးကြီးတယ်ဆိုတာ နားလည်လာပါတယ်။

## Hardware Wallet ဆိုတာဘာလဲ

Hardware Wallet ဆိုတာ Private Key ကို သီးသန့် Hardware Device တစ်ခုထဲမှာ ထိန်းသိမ်းထားတဲ့ Wallet ဖြစ်ပါတယ်။ အများအားဖြင့် USB Device ပုံစံမျိုးရှိပြီး Computer နဲ့ ချိတ်ဆက်အသုံးပြုရပါတယ်။ Trezor, Ledger Nano, Digital Box နဲ့ KeepKey လို Hardware Wallet တွေပါ။

Hardware Wallet တွေမှာ Screen နဲ့ Security Features တွေ ပါဝင်ပြီး Transaction ပြုလုပ်တဲ့အခါ အချက်အလက်တွေကို စစ်ဆေးနိုင်အောင် ကူညီပေးပါတယ်။

ဒါပေမယ့် Hardware Wallet တစ်ခုရှိရုံနဲ့ လုံခြုံမှုအပြည့်အဝ ရရှိသွားတာ မဟုတ်ပါဘူး။ Device အစစ်အမှန်ဖြစ်မဖြစ်၊ Seed Phrase ကို ဘယ်လို Backup လုပ်ထားသလဲ၊ Official Software ကို အသုံးပြုသလားဆိုတာတွေကလည်း အရေးကြီးပါတယ်။

## Hot Wallet နဲ့ Cold Wallet

Hot Wallet ဆိုတာ Internet နဲ့ ချိတ်ဆက်အသုံးပြုရတဲ့ Online Wallet ဖြစ်ပါတယ်။

ဥပမာ...

- Exchange Wallet
- Mobile Wallet
- Browser Wallet
- Desktop Software Wallet

တို့ ဖြစ်ပါတယ်။

Hot Wallet တွေက အသုံးပြုရလွယ်ကူပြီး ငွေလွှဲခြင်း၊ ငွေလက်ခံခြင်း၊ Online Transaction ပြုလုပ်ခြင်းတွေကို လျင်မြန်စွာ လုပ်ဆောင်နိုင်ပါတယ်။ Cold Wallet ကတော့ Private Key ကို Internet နဲ့ အမြဲတမ်း တိုက်ရိုက်မချိတ်ဆက်ထားတဲ့ Offline Storage နည်းလမ်း ဖြစ်ပါတယ်။

အဲဒီနှစ်မျိုးကို ကျွန်တော်နားလည်လွယ်အောင် ဒီလိုမှတ်ထားပါတယ်...

- **Hot Wallet = Checking Account**
- **Cold Wallet = Savings Account**

နေ့စဉ်အသုံးပြုဖို့လိုတဲ့ ပမာဏကို Hot Wallet ထဲမှာသာ ထားပြီး ရေရှည်ထိန်းသိမ်းလိုတဲ့ Asset တွေကို Cold Wallet ထဲမှာ ပိုမိုလုံခြုံစွာ သိမ်းဆည်းဖို့ စဉ်းစားနိုင်ပါတယ်။

## Exchange Wallet နဲ့ ကိုယ်ပိုင် Wallet

Cryptocurrency Security မှာ အရေးကြီးဆုံး မေးခွန်းတစ်ခုက...

**“Private Key ကို ဘယ်သူထိန်းချုပ်ထားသလဲ”** ဆိုတာ ဖြစ်ပါတယ်။ Exchange Wallet သို့မဟုတ် Custodial Wallet တွေမှာ Private Key ကို Service Provider က ထိန်းချုပ်ထားနိုင်ပါတယ်။ Self-Custody Wallet တွေမှာတော့ Private Key ကို ကိုယ်တိုင်ထိန်းချုပ်ရပါတယ်။

ဒါကြောင့် အသုံးပြုရလွယ်ကူမှုနဲ့ ကိုယ်ပိုင်ထိန်းချုပ်မှုကြားမှာ Balance တစ်ခုရှိပါတယ်။ Exchange Account သုံးတာက လွယ်ကူနိုင်ပေမယ့် ကိုယ့်ရဲ့ Private Key ကို ကိုယ်တိုင်မထိန်းချုပ်နိုင်တဲ့အခြေအနေ ရှိနိုင်ပါတယ်။

## Wallet တစ်ခုတည်းမှာ အားလုံးမထားသင့်ဘူးလား

Course ထဲမှာ Wallet အမျိုးမျိုးကို လေ့လာဖို့ အကြံပြုထားတဲ့အကြောင်းရင်းက နိုင်ငံအလိုက် အသုံးပြုခွင့် မတူနိုင်တာ၊ Cryptocurrency Support မတူနိုင်တာနဲ့ Risk ကို တစ်နေရာတည်းမှာ မစုစည်းထားချင်တာတို့ကြောင့် ဖြစ်ပါတယ်။

ဒါပေမယ့် Wallet များများသုံးခြင်းက Backup နဲ့ Recovery Management ကို ပိုမိုရှုပ်ထွေးစေနိုင်တာကိုလည်း မမေ့သင့်ပါဘူး။ အဓိကက Wallet များများထားဖို့ထက် ကိုယ့်ရဲ့ Risk, Knowledge နဲ့ Backup Capability နဲ့ ကိုက်ညီတဲ့ စနစ်တစ်ခုကို ရွေးချယ်ဖို့ ဖြစ်ပါတယ်။

## Online Security ကို ဘာကြောင့် သတိထားရသလဲ

ယနေ့ခေတ်မှာ Smart Home Device တွေ၊ IoT Device တွေ၊ Online Services တွေ ပိုမိုများပြားလာပါတယ်။ Smart Camera, Smart Lock, Smart Air Conditioner, Smart Speaker စတဲ့ Device တွေဟာ Internet နဲ့ ချိတ်ဆက်ထားတာကြောင့် Network Security ကိုလည်း ဂရုပြုဖို့ လိုအပ်လာပါတယ်။

Security Vulnerability တွေကို ပြင်ဆင်ဖို့ Operating System Update, Firmware Update နဲ့ Security Patch တွေကို အချိန်မီ ပြုလုပ်သင့်ပါတယ်။ Hardware Wallet ကို အသုံးပြုပြီးတဲ့အခါလည်း မလိုအပ်ဘဲ Computer နဲ့ အမြဲတမ်း ချိတ်ထားမယ့်အစား အသုံးပြုပြီးရင် ဖြုတ်ထားတာက ကောင်းမွန်တဲ့ Operational Security Practice တစ်ခု ဖြစ်နိုင်ပါတယ်။

## Cryptocurrency မှာ ကိုယ်တိုင်ဘဏ်ဖြစ်လာခြင်း

Cryptocurrency ကို Self-Custody နည်းလမ်းနဲ့ အသုံးပြုတဲ့အခါ ကိုယ့်ရဲ့ Wallet ဟာ ကိုယ့်ရဲ့ Bank Account လို ဖြစ်လာပါတယ်။ ဘဏ်မှာ Password တစ်ခုတည်းနဲ့ လုံခြုံရေးမပြည့်စုံသလို Cryptocurrency Wallet မှာလည်း Single-Factor Authentication တစ်ခုတည်းကို မမှီခိုသင့်ပါဘူး။ Strong Authentication, Secure Backup, Phishing Awareness နဲ့ Private Key Protection တွေကို တွဲဖက်စဉ်းစားသင့်ပါတယ်။

အရေးကြီးဆုံးကတော့...

**ကိုယ့်ရဲ့ Private Key ကို ကိုယ်တိုင်ထိန်းချုပ်မယ်ဆိုရင် ကိုယ့်ရဲ့ Security တာဝန်ကိုလည်း ကိုယ်တိုင်ယူရမယ်** ဆိုတာပါ။
